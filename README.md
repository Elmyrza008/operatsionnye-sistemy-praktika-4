# Операционные системы. Практические работы

Домашняя работа по предмету «Операционные системы».

ФИО: ____________________

## Состав

- `pr01` — Linux, терминал, права и базовая диагностика.
- `pr02` — Bash и системные вызовы.
- `pr03` — процессы Linux, `fork`, `exec`, `wait`, `/proc`.
- `pr04` — потоки, процессы, GIL и сравнение производительности.
- `pr05` — симулятор планирования CPU.
- `pr06` — синхронизация, мьютексы, семафоры, condition variable.
- `pr07` — IPC: pipe, FIFO, сигналы, Unix socket, shared memory.
- `pr08` — взаимоблокировки и алгоритм банкира.

## Среда

Рекомендуемая среда: Ubuntu 22.04+ или WSL2.

Установка базовых пакетов:

```bash
sudo apt update
sudo apt install -y python3 build-essential make gdb strace valgrind htop
```

Каждая работа запускается из своей папки. Команды указаны в `README.md` внутри `prNN`.
